# Mapzzz
Android app for navigation that supports walking, cycling, driving and public transport, with data from gtfs.




## AI usage guidelines

### You can:
* Check spelling with AI
* Use AI generated code as a proof of concept
* Use AI **to help you** find bugs
* Ask AI about an idea on how to do something

### You can't:
* Sumbit a PR with **any** AI generated code
* Write a PR or an issue with AI

### You have to:
* State how you used AI in discussion, PRs and issues
